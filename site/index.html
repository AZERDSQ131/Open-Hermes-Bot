Grok Bot is the window. Hermes is the engine.

Grok Bot does not run your agents, hold their memory, or choose the model that answers. Hermes does all of that, on the machine you already run it on. The app connects to it and gives it a native Mac window.

Hermes keeps

  • The agents, their profiles and their names
  • Every conversation, as a session
  • What each agent remembers
  • The models, the tools and the quota

Grok Bot adds

  • A native window, a Keychain and dictation
  • Groups, where agents answer each other
  • Tapbacks, mentions and silence
  • A face for every agent
  • No API to writeYou do not call anything yourself.
  • No key per agentThe app creates them on the host.
  • No service to runHermes is already there.
  • Nothing kept locallyNo file, no localStorage.

A group is a room, not a broadcast.

One message asks every member at once. A member with nothing to add says so, and the app leaves a tapback in its place.

Everyone is asked at once

One message makes one request per agent, in parallel. A later wave only includes the agents the previous line mentioned.

A tapback says who tapped

In a group, reactions are signed, so two agents can tap the same line. Click the pill to see which ones did.

Ship it once the rollback path is green.
  • @Name hands the floor over, and the mentioned agent answers next.
  • A round stops after eight spoken lines, and no member speaks more than twice.
  • Type @ in the composer to pick a member from the roster.
  • Each member answers with its own model, in its own session, with its own memory.

Give every agent a face.

Eight shapes and twelve colours. The name, the colour and the shape are written into the agent's own profile on the host, so an agent that comes back after a restart is the same agent.

When a model runs out, another one answers.

The chip in the composer lists the models your providers offer. If the model you picked is out of quota, the turn is retried on a free model from the same provider, and the thread says so.

  • A pick is remembered per agent, so the next thread starts there.
  • Only authenticated providers are listed.
  • A model you chose by hand is never overwritten.

Two fields, then you are in.

The connection is an SSH host and one API key. The key goes to the macOS Keychain, or comes straight from the server. The per-agent keys are made on the host, by the app.

A conversation is a Hermes session, and Hermes is the only place it is kept. Grok Bot writes nothing on this Mac: no file, no keychain entry, no localStorage.

Build it from source.

Electron, React and TypeScript. The test suite covers the protocol, the transcript reader and the group rules, and the build fails when a line of them stops being exercised.
