Message the group

A group is a room, not a broadcast.

One message asks every member at once, and their answers stream side by side. A member with nothing to add says so, and the app leaves a tapback in its place, so an answer never simply vanishes.

Every member is asked at the same time

One message makes one request per agent, in parallel. A later wave only includes the agents the previous line mentioned.

  • @Name hands the floor over, and the mentioned agent answers next.
  • A round stops after eight spoken lines, and no member speaks more than twice.
  • Type @ in the composer to pick a member from the roster.
  • Each member answers with its own model, in its own session, with its own memory.

Give every agent a face.

Eight shapes and twelve colours. The name, the colour and the shape are written into the agent's own profile on the host, next to the metadata Hermes already paints it with. An agent that comes back after a restart is the same agent.

When the quota runs out, the answer still lands.

Grok Bot remembers the model each agent last answered on, so a new conversation starts where the last one finished. When the chosen model is exhausted, the turn is retried on a free model from the same provider, and the thread says so.

Where it lives

The conversation never touches this Mac.

A conversation is a Hermes session, and Hermes is the only place it is kept. Grok Bot reads it back over an SSH tunnel and writes nothing locally: no file, no keychain entry, no localStorage. Close the app, wipe the machine, install it again, and the thread is still there.

ssh tunnel to the Hermes host 
ssh -o BatchMode=yes -o ExitOnForwardFailure=yes \
  -N -L 127.0.0.1:18742:127.0.0.1:8642 my-hermes-host

Keychain

The API key is kept in the macOS Keychain, in an item Grok Bot owns. It is never written by the app and never sent anywhere but the host.

Microphone

Dictation is the only thing macOS asks permission for. The words are transcribed on your own host, and they land in the composer so you can read them before sending.

Native chrome

Native traffic lights, a hidden inset title bar, and a window that behaves like the rest of the desktop rather than like a web page in a frame.

Build it from source.

Electron, React and TypeScript. The test suite covers the protocol, the transcript reader and the group rules, and the build fails when a line of them stops being exercised.

npm install
npm run dev
