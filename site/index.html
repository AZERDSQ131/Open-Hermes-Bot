Grok Bot is an interface for Hermes.

Hermes is the harness: it runs the agent loop, keeps the memory, owns the conversations, executes the tools and calls the models. Grok Bot is the macOS shell in front of that. It runs no model and keeps no transcript.

Hermes, the harness

  • The agent loop and the memory
  • The conversations, as sessions
  • The tools it executes
  • The models it calls, and the quota

Grok Bot, the interface

  • The room the bots share
  • The identity of every bot
  • The group protocol, the waves and the silence
  • The way a turn reads
  • No API to writeYou call no model yourself.
  • No key per botThe app makes them on the host.
  • No account, no cloudThe host you already use.
  • Nothing kept locallyNo file, no localStorage.

A group is a room, not a broadcast.

One message asks every member at once: one wave, every member asked in parallel, the answers streaming side by side. A member with nothing to add says so, and the app leaves a tapback in its place.

One wave, everyone asked

One message makes one request per bot, in parallel. A later wave only includes the bots the previous line mentioned.

A tapback says who tapped

In a group, a tapback is signed, so two bots can tap the same line. Click the pill to see which ones did.

Ship it once the rollback path is green.
  • @Name hands the floor over: that bot answers the next wave.
  • A wave stops after eight spoken lines, and no member speaks more than twice.
  • Type @ in the composer to pick a member from the roster.
  • Each member answers through its own session, with its own memory.

Give every bot a face.

A bot is a Hermes profile with a face: a name, a colour and a shape, carried in the metadata of its own profile on the server. Eight shapes, twelve colours. A bot that comes back after a restart is the same bot.

When a model runs out, another one answers.

The chip in the composer lists the models the providers offer. If the model you picked is out of quota, the turn is retried on a free model from the same provider, and the thread says so.

  • A pick is remembered per bot, so the next thread starts there.
  • Only authenticated providers are listed.
  • A model you chose by hand is never overwritten.

Two fields, then you are in.

The SSH host of the machine running Hermes, and its API key. Press Import from host and the app reads the key from the host itself, over the SSH it already uses. Nothing else is needed: no account, no cloud, no key typed by hand.

A conversation is a view of a session, not a copy of it. The transcript lives in the session, on the host, and nowhere else: no file on this Mac, no keychain entry, no localStorage.

Take the app, or build it.

The releases page carries the disk image and the zip. Or clone it: Electron, React and TypeScript, with a test suite that covers the protocol, the transcript reader and the group rules, and a build that fails when a line of them stops being exercised.
